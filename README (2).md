# Secure Application Integration

Integrated responsive internship frontend + Node.js/Express API.

Features: API loading/failure/retry states, search/filtering, client and server validation, secure headers, rate limiting, parameterized SQLite queries, escaped rendering, and automated tests.

## Run
`npm install`
`npm start`

Open `http://localhost:3000`.

## Test
`npm test`
